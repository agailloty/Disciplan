# Connecteur MCP Disciplaner

Conception d'un connecteur MCP (Model Context Protocol) exposant Disciplaner aux clients LLM (Mistral, ChatGPT, Claude Desktop, Cursor...) afin de déléguer les opérations du produit : création de tickets, commentaires, clôture, sprints, enrichissement de backlog.

1. [Conception architecturale](01-conception-architecture.md)

Document de conception — aucune implémentation livrée à ce stade. Il s'applique au code de la branche `feat/flutter-migration` (API ASP.NET Core 10 dans `src/Disciplaner.Web/Server`, services applicatifs dans `src/Disciplaner.Application`).
